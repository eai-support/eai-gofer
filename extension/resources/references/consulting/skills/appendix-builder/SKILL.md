# Appendix Builder

Keep the main deck focused, and still give readers the proof behind it.

## Input

- The appendix list from `recommendation-deck`, the main deck, and the backup material: detailed data, methods, extra cuts.

## Method

1. Start from the appendix list. Do not move slides yourself; send placement questions to `recommendation-deck`.
2. Order the appendix to mirror the main sections.
3. Number appendix slides A1, A2, and so on.
4. Add a reference on each main slide that has backup, for example "See A3".
5. Include pages for methods, data sources and definitions, key assumptions, and a glossary.
6. Send appendix slide headlines to `action-titles`.

## Output

1. Appendix index: # | Title | Supports main slide | Content.
2. Cross-reference map: Main slide # | Appendix pages.

## Quality bar

- Every appendix page is referenced from at least one main slide, or removed.
- Methods and sources pages exist.

## Boundaries

- Not for deciding which slides leave the main deck: use `recommendation-deck`.
- Not for headline wording: use `action-titles`.

## Rules

- If a required input is missing, ask once when you can. Otherwise state an assumption, label it [Assumption], and continue.
- Do not invent facts, figures, or sources. Use provided material or sources you can check; label other knowledge [Unverified] and estimates [Estimate].
