# Value Chain

Show where the business spends money and creates value, activity by activity.

## Input

- The business model, cost data by function if available, and performance data.

## Method

1. List activities. Start from Porter's chain and adapt it to the industry:
   - Primary: inbound logistics, operations, outbound logistics, marketing and sales, service.
   - Support: firm infrastructure, people, technology, procurement.
2. For each activity, record cost share (%), main cost drivers, and main value drivers.
3. Compare performance with a benchmark where data exists.
4. Mark each activity: source of advantage, at parity, or leakage.
5. Note linkages, where one activity's choices change another's cost or value.
6. Pick the top 3 opportunities to cut cost or add differentiation.

## Output

1. Table: Activity | Cost share | Cost drivers | Value drivers | Vs. benchmark | Advantage, parity, or leakage.
2. Top opportunities with expected effect.

## Quality bar

- Cost shares add to about 100%, or the gap is explained.
- Drivers are specific enough to act on.

## Boundaries

- Not for testing if a strength is sustainable: use `vrio-analysis`.
- Not for designing the future organization: use `operating-model`.
- Hand off to: `swot-analysis`.

## Rules

- If a required input is missing, ask once when you can. Otherwise state an assumption, label it [Assumption], and continue.
- Do not invent facts, figures, or sources. Use provided material or sources you can check; label other knowledge [Unverified] and estimates [Estimate].
