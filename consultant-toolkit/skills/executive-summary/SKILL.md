# Executive Summary

Write the one page that a busy reader may read instead of the whole deliverable.

## Input

- The finished deliverable or its pyramid, and the audience (from `audience-brief` if available).

## Method

1. Open with the answer in one or two sentences.
2. Give 3 to 5 supporting points. Each has one key number.
3. State the implication or recommendation.
4. End with next steps and asks: who does what, by when.
5. Keep it to one page, about 250 to 350 words.
6. Make it stand alone: a reader who reads only this page understands the answer.
7. Add nothing that is not in the body. Use the same numbers as the body.

## Output

The summary, as headed paragraphs or answer-first bullets.

## Quality bar

- The answer is in the first sentence.
- Every number matches the body.

## Boundaries

- Not for a document whose reader must approve a decision, even when a deck exists: use `decision-memo`.
- Not for slide headlines: use `action-titles`.

## Rules

- If a required input is missing, ask once when you can. Otherwise state an assumption, label it [Assumption], and continue.
- Do not invent facts, figures, or sources. Use provided material or sources you can check; label other knowledge [Unverified] and estimates [Estimate].
