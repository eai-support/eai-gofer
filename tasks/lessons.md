# Lessons

- A writing standard is not enough by itself. Require a final response check and
  rewrite before sending.
- Keep the same user-facing rule in public skills, host instructions, and
  generated workspace instructions.
- A local Object Type dry run proves the source pairs and preferred request
  shape. It does not prove the deployed backend accepts that shape. Require a
  machine-readable safe-negotiation capability before mutation and preserve
  historical slugs when compatibility would otherwise be lossy.
