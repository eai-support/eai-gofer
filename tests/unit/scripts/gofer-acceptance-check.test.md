# Real Acceptance And Recovery Tests

These are local process tests, not native model or desktop qualification.

## Acceptance Checks

- Execute reviewed absolute programs without a shell.
- Reject unapproved checks and mutable command replacement.
- Require the real exit result, not success text.
- Keep bounded output in private receipt files.
- Fail on timeout, cancellation, unavailable programs and changed inputs.
- Supply failed checks and receipts to the next bounded repair attempt.
- Do not start work while a recorded business question is waiting.

## Recovery Inspection

- Preserve the original journal, consumed calls and attempts.
- Reject truncated, malformed, stale, oversized or changing journals.
- Require trusted worker inspection and fresh receipt verification.
- Keep uncertain side effects blocked after a real child process exits.
- Never automatically replay, reset limits or grant resume from inspection alone.

## Remaining Qualification

Reviewed command configuration is trusted application code. This is not a sandbox.
Native model execution, remote cancellation, atomic task commits and automatic
restart remain separate qualification requirements.
